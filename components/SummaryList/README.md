# SummaryList

Receipt-style key/value rows in a rounded container, with an optional emphasised total.

**Provide:** `rows` (`[{label, value, tone?, total?}]`; `tone` is `positive` or `error`), optional `footnote`.

- Values are right-aligned with tabular numerals; prefix estimates with ≈.
- Use for order review, checkout totals, position details and system specs.
- A free item says "Free" in `positive`, never "$0.00".
