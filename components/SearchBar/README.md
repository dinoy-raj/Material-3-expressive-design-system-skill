# SearchBar

Full-width pill search field on `surface-container-high`.

**Provide:** `placeholder` naming what can be found ("Search stocks, funds and crypto", "Search titles, authors, ISBNs"), optional `defaultValue`, `onChange`, `icon` (leading), `trailing` (an avatar or mic icon button).

- Place it directly under the screen title, 16px gutters.
- A clear button replaces the trailing slot once there is text.
- Tapping it on a phone opens a full-screen search view with recent and suggested results as list items.
