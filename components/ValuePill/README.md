# ValuePill

Price or percentage with a direction arrow, coloured by gain or loss.

**Provide:** `children` (the formatted value, e.g. "$389.16" or "0.35%"), `direction` (`up` or `down`), `solid` for the strong filled list-trailing style, `inline` for a coloured delta in running text.

- Always pair colour with the arrow glyph so gain and loss read without colour.
- Use solid pills at the trailing edge of watchlists, inline deltas under a hero price ("▲ $1,090.75 (3.84%) Past month").
