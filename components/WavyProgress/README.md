# WavyProgress

Linear progress whose completed part is a wave, ending in a stop dot.

**Provide:** `value` (0 to 1), optional `label`, `animated` for an in-flight state (the wave travels), `flat` for a calm straight version.

- Use for goals the person is moving toward: lesson progress, "Add $16.50 more for free delivery", delivery steps.
- Keep the wave for progress that is good news; use `flat` for neutral quotas such as storage.
