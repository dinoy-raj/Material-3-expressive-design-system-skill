# Badge

Small status pill or count for states, tags and notifications.

**Provide:** `children` (one to three words), `tone` (`primary`, `tertiary`, `positive`, `error`, `highlight`, default neutral), `mono` for uppercase status codes, `dot` for a leading status dot, or `count` for a notification number.

- Mono + dot is the status vocabulary: PENDING, PALETTE, TYPE, QUOTE.
- Tonal badges tag offers and items: Best, +30%, Warm, Popular, 1 free night.
- `count` sits on a nav icon or avatar; cap at 99+.
- Never use a badge as a button.
