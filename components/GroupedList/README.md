# GroupedList

Settings-style group: stacked segments 2px apart, large outer corners, small inner corners.

**Provide:** `children` (each child becomes one segment: a Switch row, a ListItem, a ButtonGroup with a heading), optional `title` (shown in `primary`, sentence case).

- This is the M3 Expressive list shape: the group reads as one object while each row stays separately pressable.
- Use for settings, preferences and account details. Put a ButtonGroup inside a segment for theme or unit choices.
