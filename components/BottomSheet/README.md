# BottomSheet

Modal sheet that rises from the bottom with a drag handle and `shape-xl` top corners over a scrim.

**Provide:** `children` (the form or content), optional `title` (display serif), `eyebrow` (mono status badge naming the sheet type: TYPE, PALETTE, QUOTE), `eyebrowTone`, `subtitle`.

- Use for focused creation and quick edits that keep the screen behind in view: capture a palette, add play money, set a sleep window.
- The primary action sits at the bottom of the sheet, full width.
- The preview renders the sheet in place; in an app, position it fixed to the bottom and trap focus.
